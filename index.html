BigQuery는 데이터 엔지니어링이 아니라 삼성전자 마케팅 DB의 조회와 분석 활용 범위입니다. 복잡한 SQL은 추출 조건과 로직을 정의해 데이터 담당자와 협업합니다. AI와 AX 역시 모델 개발이 아니라 분석 업무 구조와 자동화 도구의 기획, 검증, 활용이 중심입니다.

이 페이지에 대해

  • 목적 이력서와 포트폴리오를 대신하지 않고, 전체 경력의 관계와 확장 흐름을 살펴보는 보조 자료입니다.
  • 만든 방식 경력 기준 데이터로 정보 구조를 설계하고, 생성형 AI의 도움을 받아 HTML, CSS, JavaScript로 구현한 뒤 반복 검수했습니다.
  • 기술 범위 소프트웨어 엔지니어링 역량을 주장하려는 것이 아니라, 업무 요구사항을 구조화하고 AI를 활용해 실제로 작동하는 결과물로 만드는 방식을 보여 줍니다.
  • 도식 도식은 구조를 설명하려고 새로 그린 것이며 실제 데이터나 업무 화면이 아닙니다. 기간과 단축 효과는 실무 기준 추정입니다.
